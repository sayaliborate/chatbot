# 🤖 AI Chatbot

A simple and user-friendly AI Chatbot built using **FastAPI**, **LangChain**, and **Ollama**.  
It features a clean hacker-style dark UI that is easy to use even for non-technical users.

---

## ✨ Features

- 💬 Real-time AI chat
- 🧠 Powered by local LLM (Ollama – Phi-3)
- ⚡ FastAPI backend
- 🌐 Simple HTML, CSS & JavaScript frontend
- 🔐 No API keys required (runs locally)

---

## 🛠️ Tech Stack

- **Backend:** FastAPI, LangChain, Ollama
- **Frontend:** HTML, CSS, JavaScript
- **Model:** Phi-3 (via Ollama)
- **Language:** Python
